# Motion

- CSS keyframes only, defined in `styles.css` under `@theme` and used as `animate-pop`, `animate-fade-up`, `animate-slide-in`, `animate-grow-x` / `animate-grow-y` (with `origin-left` / `origin-bottom`), `animate-float`, `animate-wiggle`, `animate-pulse-ring`, `animate-burst`, `animate-draw` (SVG stroke), `animate-progress`, `animate-drift` (backdrop), `animate-dot`; `glow-border` adds a slowly rotating gradient ring. No animation library: nothing to download, and the global reduced-motion rule ends every animation at once.
- Animate `transform` and `opacity` only. Lists stagger with `style={stagger(index)}` from `lib/motion.ts`.
- Entrance animations run on mount. Game screens are keyed by phase and question id, so a snapshot that only changes `answeredCount` never replays them; an element that should pop on every change is keyed by that value on purpose (the player counter).
- JS-driven effects go through `lib/motion.ts`: `useMotionOk()` / `motionOk()` for `prefers-reduced-motion`, `useCountUp()` / `<CountUp>` for numbers. Confetti is `celebrate()` in `lib/confetti.ts` (lazy `canvas-confetti`, no worker because of the CSP, skipped under reduced motion).
- `Backdrop` (three drifting colour blobs behind every page) is mounted once in the root layout.
- **Press wobble**: `installSquish()` (`lib/squish.ts`, installed in the root layout) gives every clicked button, button-like link, menu item and `[data-squish]` element (choice cards) a short "bubble gum" squash and stretch through the Web Animations API with `composite: 'add'`, so it stacks on hover lifts and entrance animations without restarting them. Nothing to add per component; opt out with `data-no-squish`. A press that turns a choice off (a checked switch, checkbox, radio or `aria-pressed="true"` button, read before the click) gets a soft dip instead (`isUnselecting`): the wobble is for choosing. Only `MouseEvent` clicks count: Radix fires a plain `Event('click')` on the hidden input of every radio, checkbox and switch whose state changes, including the option just unchosen. Radio dots stay mounted (`forceMount`) and scale in with a spring, out quietly.
- **In and out**: `usePresence(show)` (`lib/presence.ts`) keeps an element mounted while it plays `animate-pop-out`, then unmounts it on `animationEnd` (the save bar, the message on show, Reset buttons); a removed list row sets its own `leaving` state and calls the real removal from `onAnimationEnd`. `SmoothHeight` (`components/smooth-height.tsx`) springs a panel to its content's new height (a `ResizeObserver` plus a height transition). `TabsContent` plays `animate-panel-swap` on every tab change. Rows already there when a list opens stay still; only added ones pop.
- **Toasts** reuse the host message's `note-in` fall on `[data-mounted]` with `backwards` fill (Sonner's own transform takes over after it) and leave with `toast-out`, which must fit Sonner's 200 ms before unmount. From `sm` they are as wide as the page's panels (48rem; `--width` with `!important`, Sonner sets it inline), and beside the host sidebar (`[data-host-sidebar]`, found with `:has()`) they centre on the page's column, 136 px right of the window's centre.
- **Reorders with buttons or keys slide**: `useFlip(container)` (`lib/flip.ts`) returns `capture(movedId)`; call it just before the order changes and every `[data-flip-id]` element slides from its old place to the new one (the moved one lifted). For a list reordered from outside (the editor's toolbar and shortcuts), `useFlipOnReorder` keeps positions after each reorder and slides on a change of the order string; a drag sets its `skip` ref, since dnd-kit animates drags itself. Removing a row: `capture()` before removal so the rows below close the gap.
- **Save bars over content** get a blurred halo of the page colour (`before:` with `blur-2xl`) instead of a gradient strip, which shows hard edges against the backdrop.
- **Sidebar**: one highlight behind the main links (`SlidingItems` in `host-nav.tsx`) springs to the active link on every path change; the active icon wiggles. Phone tab icons pop and wiggle when they become active.
- **Hover lifts**: anything that rises on hover (`hover:-translate-y-*`) is positioned and gets `hoverBridge` from `components/ui/button.tsx` (an invisible strip below it while hovered); without it a pointer on the bottom edge loses and regains the hover in a loop. Solid buttons, answer options, choice cards and the type picker have it.
- Menus and select lists open with `animate-menu-pop`, dialogs with `animate-dialog-pop`, popovers (the date picker) with `animate-bubble-pop`: an elastic, uniform scale out of the corner at the trigger (Radix's `--radix-popover-content-transform-origin`; don't override the origin), so the panel shoots out in the direction it opens. The user rejected a squash and stretch along the opening diagonal, which reads as a skew on a rectangle, and a vertical squash from the edge's middle. These entrances are the primitives' defaults; screens never add their own. Radix moves a popover with its anchor every frame, so the trigger's press wobble would shake it: anchor the popover to a still wrapper (`PopoverAnchor` around the trigger) and keep the trigger's wobble. To change a primitive's entrance, change its default class: tailwind-merge keeps two `data-[state=open]:animate-*` classes and the one later in the stylesheet wins. Springy transitions use the easing tokens `ease-spring` (small overshoot: focus rings, switch thumbs, icons) and `ease-spring-soft` (large moves: sheets, the editor's column change, progress bars).
- The editor's settings choreography animates `grid-template-columns` (four fixed tracks at `xl`, no grid gap, spacing inside the side columns) and slides each side panel inside an `overflow-x-clip` wrapper anchored to the moving edge. Keep track counts equal between states, or the browser jumps instead of interpolating.
- Nothing appears or disappears in place: content that comes and goes with a setting goes in `Collapse` (`components/collapse.tsx`: grid rows 0fr ↔ 1fr with a spring, stays mounted, `inert` and `invisible` once closed). Inside a flex column with a gap, give it `className="-mt-6"` and `innerClassName="pt-6"` (the gap's size) so a closed one leaves no gap. Text that is cleared as it closes (a help line, an error) keeps its last value while closing.
- Scrollbars are styled globally in `styles.css` (pill thumb in the theme colour, plumper on hover); Firefox gets the thin `scrollbar-color` variant. Only inside `@media (hover: hover) and (pointer: fine)`: any `::-webkit-scrollbar` rule turns Android's overlay scrollbar into a classic one that takes 14 px and never hides.
- The projector's results summary (`useSlideshow`) moves on every 8 s and can be paused (button or P); resuming keeps the time that was left.
- Host messages fly in and out with an elastic animation and show their remaining time as a progress bar on the message itself.
- **Cow antics** (phase 32): `useCowAntics` (`features/cow/use-cow-antics.ts`) sets one antic at a time from the pure, tested `features/cow/antics.ts` (random pause, never the same twice, nothing while hidden or under reduced motion); `CowLogo` puts it on its root as `data-antic`, and the "Cow antics" block in `styles.css` animates the part (`.cow-eye-right`, `.cow-pupil-*`, `.cow-tongue`, `.cow-nostrils`, the whole `.cow`). Antics are one-off, so they add no endless animation. Each eye wrapper is clipped (`clip-path: circle`) to its white so moving pupils stay inside. Seasonal looks are extra layers chosen by `seasonFor(date)`. In development, `?cow=<season>` and `?cowAntics=fast` on the first page load try them.

## Performance rules (learned in phase 16)

- Animate HTML elements, not parts inside an SVG: Chrome runs transform animations of HTML elements on the compositor, but animating an SVG child repaints the SVG on the main thread every frame. To move parts of a drawing, stack one `<svg>` per part in absolutely positioned wrappers and animate the wrappers (`CowLogo` in `components/cow-logo.tsx`).
- An element with an SVG `transform` attribute loses it when CSS animates its `transform`; animate a wrapper instead.
- Every running animation still costs a little main-thread time (about 2 ms per 5 s each on a 4× slowed CPU), even on the compositor and with `will-change`. Keep endless idle animations few (the home pages run 21 in all).
- Never fade the largest text of a page in from `opacity: 0`: the largest contentful paint waits until it is visible. Use transform-only entrances for headings and taglines.
- The reduced-motion rule ends animations at their last keyframe. An animation that ends hidden (the cow's speech bubble) needs `animation: none` in the reduced-motion block, or it never shows.
- Measure before and after with the phone profile script described in `browser-checks`.
